# Odds Tracker

Отслеживает резкие скачки коэффициентов (в первую очередь на азиатских/шарповых
конторах — Pinnacle, SBOBET/Singbet, IBCBET, Maxbet, 1xBet) по футболу, теннису
и киберспорту (CS2, LoL, Dota2), шлёт алерты в Telegram и держит живой
HTML-дашборд. На дашборде и в дайджестах есть два независимых среза: **sharp
vs public** (кто двигается первым — умные деньги или массовый рынок) и
**Азия vs Европа** (чисто географическое сравнение средних коэффициентов).

## Как это устроено

1. `odds_client.py` — тянет текущие коэффициенты с OddsPapi (`api.oddspapi.io`).
2. `storage.py` — кладёт каждый снимок в SQLite (`data/odds_history.db`).
3. `detector.py` — сравнивает новый снимок с предыдущим по каждой линии
   (контора + матч + рынок + исход) и помечает скачок, если изменение
   превышает `SPIKE_THRESHOLD_PCT` (по умолчанию 8%). Скачки на азиатских
   конторах всегда идут первыми в списке.
4. `consensus.py` — считает две сводки по всему батчу разом: `sharp_vs_public`
   (средняя цена на шарп-конторах против паблик-контор) и `region_breakdown`
   (средняя цена на азиатских конторах против европейских/остальных) —
   расхождение ≥5% попадает в сводку.
5. `notifier.py` — шлёт скачки и обе сводки в Telegram.
6. `dashboard.py` — перезаписывает `dashboard/index.html` на каждом прогоне,
   с отдельными карточками "Азия vs Европа" и "Sharp vs public".
7. `main.py` — один цикл: fetch → save → detect → notify → dashboard.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# впиши свои ключи в .env
```

Нужно два ключа:

- **ODDSPAPI_KEY** — регистрация на https://oddspapi.io, бесплатный тариф,
  карта не нужна.
- **TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID** — напиши `@BotFather` в Telegram,
  `/newbot`, получишь токен. Потом напиши что угодно своему новому боту и
  открой `https://api.telegram.org/bot<TOKEN>/getUpdates` — там будет твой
  `chat_id`.

Перед первым запуском узнай нужные `tournamentIds` для своих лиг:

```python
import odds_client
print(odds_client.list_tournaments(odds_client.list_sports()[0]["id"]))
```

и подставь их в `main.py` вместо `DEMO_TOURNAMENT_IDS`.

## Проверка без ключей

```bash
python test_mock.py
```

Прогоняет весь пайплайн (storage → detector → dashboard) на синтетических
данных — показывает, что логика скачков и дашборд работают, ещё до того как
подключишь реальный API-ключ.

## Как запускать постоянно

Два варианта, на выбор:

### A. GitHub Actions (рекомендую) — раз в 5 минут

В репозитории уже лежит `.github/workflows/poll.yml`. Нужно:

1. Запушить этот проект в свой (можно приватный) GitHub-репозиторий.
2. Settings → Secrets and variables → Actions → добавить `ODDSPAPI_KEY`,
   `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
3. Всё — воркфлоу сам гоняется каждые 5 минут, историю коэффициентов
   переносит между запусками через `actions/cache`.

Это даёт близкую к реальному времени частоту опроса бесплатно.

### B. Scheduled task прямо в этом Claude-сеанс

Можно попросить Claude поставить периодический опрос через встроенные
scheduled tasks — но у них минимальный интервал 1 час, так что для быстрых
скачков (за минуты) это грубовато. Больше подходит как дополнение — например,
часовой дайджест — чем основной канал алертов.
